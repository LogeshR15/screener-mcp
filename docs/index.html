FAQ

Common questions

What is Screener MCP?

Screener MCP is an open-source Model Context Protocol (MCP) server that gives Claude live access to Indian equity market data from Screener.in, NSE, and MCX, including company research, stock screening, financials, and portfolio tracking.

Does Screener MCP require an API key?

No API keys are required for company research. A free Screener.in login is only needed for the stock screening tools.

How do I install Screener MCP?

Run claude mcp add screener -s user -- uvx --from 'screener-mcp[ai]' screener-mcp for the full install, or drop [ai] for a lightweight install without document analysis.
